# Governance

ops-indexer is maintained by Gateway.fm and project maintainers designated by
Gateway.fm.

## Maintainer Responsibilities

Maintainers are responsible for:

- Reviewing and merging pull requests.
- Managing releases and release notes.
- Maintaining security disclosure processes.
- Enforcing contribution and conduct policies.
- Deciding compatibility and support policy for Gateway sibling repositories.

## Decision Making

Routine technical decisions are made through pull request review. Larger
changes, including licensing, release artifacts, supported deployment posture,
or public API compatibility, require maintainer approval.

## Releases

Source releases, binary releases, and container images should include the
appropriate license notices. Official binary or container artifacts should be
published with SBOM and provenance materials once the release process is ready.

## Inbound Contributions

Contributions are accepted under Apache-2.0 with DCO sign-off unless
maintainers adopt a different written inbound contribution policy.
